# Dynamic-neuro-symbolic-agent

Dynamic neuro-symbolic agent: Qwen-4B translates natural language to JSON; arithmetic via a Python AST-based evaluator and logic via Z3; evaluated with blind A/B/C setup.

## Quickstart
- Read the paper (PDF) for the full method and evaluation.
- If GitHub shows “Invalid Notebook” for the notebook, download it and open locally in Jupyter/Colab to run.

## Project materials
- Paper (PDF): `Paper_The_Dynamic_Neuro_Symbolic_Agent__Enhancing_Arithmetic_and_Logic_in_Small_Language_Models__SLMs_.pdf`
- Slides (PPTX): `Human-AI Project - Om and Domingo.pptx`
- Notebook (IPYNB): `Code_The_Dynamic_Neuro_Symbolic_Agent.ipynb`
